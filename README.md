# Arcade Library · GameDistribution catalogue

An original, responsive static game-directory website for **f1nn2010/Games**, with a dark arcade-style homepage, game icons, search, filters, icon-download buttons and a full-window player. Works on GitHub Pages without npm or server dependencies.

**Live data snapshot:** 100 GameDistribution-listed titles collected 14 October 2026. The first 50 are ordered according to GameDistribution's publicly displayed “Top 50 Games” list at that date. The remaining 50 are **other catalogue selections, not ranks #51–#100**. A complete independently verifiable *top 1,000 ranking* was not available; this project does not invent one. The remaining 900 are **not** included yet.

**Playable status:** Only games with a publicly verified official GameDistribution ID can load within the site. Other cards have a source/search fallback until their IDs are added. GameDistribution's publisher agreement and onboarding requirements apply to embedding and monetizing games. In some cases, embeds may be restricted outside a registered publishing domain.

## Features

- **Homepage:** responsive game card grid, search and sorting, Top 50 and playable filters, incremental “load more.”
- **Icons:** each card has an attractive original **generated placeholder SVG icon** (downloadable via **↓ Icon**). These are *not* the game's official cover art. You can provide `icon_url` values from an authorized source to display official images; cross-site download restrictions may open the image in a new tab instead.
- **Player:** click on a game with a verified embed to open the official remotely hosted game in a full-window iframe. Supports reload, native browser fullscreen, escaping back, mobile layouts and shareable `#/play/<slug>` links. **No game bundles are duplicated or downloaded.**
- **Expandable catalogue:** import an authorized CSV data export with verified IDs, catalog URLs and icon image URLs, up to 1,000 games by default.
- **Security:** only HTTPS and `html5.gamedistribution.com` embed URLs accepted by the importer. Title contents are HTML-escaped in the browser.

## Run locally

```
python -m http.server 8080
```

Then open http://localhost:8080. Opening `index.html` directly as `file://` can prevent `fetch('./games.json')` in most browsers.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save. The site will be accessible at `https://f1nn2010.github.io/Games/` after deployment. If Pages is not available, deploy the same files on any static host such as Vercel.

## Import more games, up to 1,000

Get authorized game metadata from your GameDistribution publisher dashboard / approved catalogue export. Create a CSV with columns:

```
title,embed_url,catalog_url,icon_url,rank
```

`embed_url` is `https://html5.gamedistribution.com/<32-character-game-id>/`, `catalog_url` is the official catalog page, `icon_url` is the HTTPS URL of authorized cover art, `rank` is an **optional verified official rank** (not a guess). When rank is unknown, leave it blank. See `approved-embeds.example.csv`.

Then run:

```
python tools/import_gd_csv.py my-export.csv --max-games 1000
```

Commit the updated `games.json`. This merges existing records by normalized title and adds new titles in CSV order; it never copies/archives game code. By default it stops at 1,000 entries. Check that your CSV matches the official publisher data and do not assign made-up popularity ranks.
